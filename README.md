## 🚀 Getting Started

### Local Setup
1. Clone the repository:
   ```bash
   git clone https://github.com/Meiyarasu-byte/pharmaceutical-portfolio.git
   cd pharmaceutical-portfolio
   ```

2. Open in browser:
   - Simply open `index.html` in your web browser
   - Or use a local server:
     ```bash
     python -m http.server 8000
     # or
     npx http-server
     ```

3. Access at: `http://localhost:8000`

### Deployment
The website can be deployed using:
- **GitHub Pages**: Enable in repository settings
- **Netlify**: Connect GitHub repository
- **Vercel**: Connect GitHub repository
- **Traditional Hosting**: Upload files via FTP

## 📝 Customization

### Update Personal Information
Edit `index.html` to update:
- Name and contact details
- Professional profile information
- Research projects and descriptions
- Skills and software expertise
- Education and experience details

### Modify Colors
Edit CSS variables in `styles.css`:
```css
:root {
    --color-primary-light: #faf8f5;
    --color-accent: #2c2c2c;
    /* ... more variables */
}
```

### Add Profile Picture
1. Place your profile image in an `assets/` folder
2. Update the profile image section in `index.html`
3. Link the image in the HTML

### Update Contact Form
The contact form currently uses a mailto link. To add backend functionality:
1. Integrate with a service like Formspree, EmailJS, or Netlify Forms
2. Update the form submission handler in `script.js`
